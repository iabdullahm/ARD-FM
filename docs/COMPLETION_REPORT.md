## 📋 خطواتك للإطلاق النهائي

1. **`npm install`** — لتثبيت حزمة `@next/third-parties` وتحديث lockfile.
2. **GA4**: أنشئ حساباً على analytics.google.com → خذ Measurement ID (`G-XXXXXXX`) → أضفه:
   - في Vercel: Settings → Environment Variables → `NEXT_PUBLIC_GA_ID`
   - محلياً: سطر `NEXT_PUBLIC_GA_ID=G-XXXXXXX` في ملف `.env`
3. **`vercel --prod`** — هذه النشرة تحمل: إصلاح الصور المكسورة + GA4 + تنظيف الديمو + تحويلات login/signup.
4. **تنظيف يدوي**: احذف `_to_delete/` ومجلد `src/ai` الفارغ و`src/app/login` و`src/app/signup` و`src/components/sections/DemoAccessSection.tsx`.
