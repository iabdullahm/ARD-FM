## Troubleshooting

**Problem**: Git lock file error
**Solution**: Close all editors/IDEs and try again

**Problem**: Vercel doesn't deploy after push
**Solution**: Check your GitHub Actions status and Vercel dashboard

**Problem**: Images look blurry
**Solution**: Hard refresh browser (Ctrl+F5)
